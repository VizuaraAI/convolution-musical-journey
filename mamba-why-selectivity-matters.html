How fixed SSMs treat every word equally — and why that’s a fatal flaw for language understanding.

Chapter 1

How a Fixed SSM Reads a Sentence

Let’s take a simple sentence and watch what a traditional, fixed-parameter State Space Model does with it.

Consider the sentence: “The capital of France is Paris”

In a fixed SSM, the recurrence that updates the hidden state at every step is:

ht = Ā × ht-1 + B̄ × xt

The critical word here is fixed. The matrices Ā and B̄ are the same for every single token, regardless of what that token means.

The SSM treats “The” with the same importance as “France”. It treats “of” — a meaningless function word — with the same weight as “Paris” — the answer to the question. It has no way to tell the difference.

This is like reading a book with the exact same level of focus on every single word. You can’t skim through “the cat sat on the” and then pay close attention to “quantum entanglement.” Every word gets equal brain power. That’s what a fixed SSM does.
Chapter 2

What Happens Inside the State

Let’s trace through the state evolution step by step and see exactly how each token’s contribution decays over time.

With Ā = 0.8 and B̄ = 0.2, each token enters the state with weight 0.2, and then decays by a factor of 0.8 with every subsequent step. After processing all five tokens, here is how much of each token’s original contribution remains in the hidden state:

"The"     : 0.2 × 0.84 = 0.082   (12.8%)
"capital" : 0.2 × 0.83 = 0.102   (16.0%)
"of"      : 0.2 × 0.82 = 0.128   (20.0%) ← more than "capital"!
"France"  : 0.2 × 0.81 = 0.160   (25.0%)
"is"      : 0.2 × 0.80 = 0.200   (31.2%)

Look at that distribution. “of” at 20% outweighs “capital” at 16%, simply because “of” came one position later. And “is” dominates the entire state at 31.2% simply because it is the most recent token — not because it carries the most meaning.

In a fixed SSM, importance = recency. The most recent token always dominates the state, regardless of meaning. The model literally cannot distinguish content from noise. “is” gets more representation than “France” — even though “France” is the key piece of information needed to predict the next word.
Chapter 3

The Mamba Fix — Content Controls Importance

Mamba’s key innovation is making the SSM parameters input-dependent. Three parameters now change with every token: Bt, Ct, and crucially, Δt (the discretization step size).

Instead of fixed Ā and B̄, Mamba computes them from the input via Δt:

Āt = exp(-Δt)     B̄t = 1 - exp(-Δt)

A small Δ means “barely let this token in.” A large Δ means “this is important — write it strongly into the state.” And the token itself decides its own Δ.

Delta is like a volume knob for each token. Small Δ = “keep the old state, barely let this token in.” Large Δ = “this is important! Flush the old state and write this token strongly.”

Notice how the function word “of” gets a tiny Δ of 0.05, while the content word “France” gets a massive Δ of 2.0. The model has learned during training that “France” carries critical information, while “of” is structural glue that can be mostly ignored.

Chapter 4

Delta — The Gatekeeper

Let’s look at what Δ actually does to the information flow. Think of it as a gate that controls how much new information enters the hidden state.

Small Δ (0.05)

Boring token: “of”

Gate almost closed — tiny trickle

Ā = exp(-0.05) = 0.951
→ 95% of old state preserved

B̄ = 0.049
→ Only 5% of input written

Large Δ (2.0)

Important token: “France”

Gate wide open — flood of information

Ā = exp(-2.0) = 0.135
→ Only 14% of old state survives!

B̄ = 0.865
→ 87% of input written!

The contrast is stark. When the gate is nearly closed (small Δ), the old state passes through almost untouched and the new token barely registers. When the gate is wide open (large Δ), the old state is largely flushed out and the new token dominates. This is exactly what we want for language: content words should write strongly, function words should be transparent.

How does the model choose Δ?
Δt = softplus(Linear(xt))

The token’s own embedding determines its delta. A learned linear projection maps the input embedding to a scalar, and softplus ensures it’s positive. The model learns which tokens deserve large deltas during training — no hand-tuning required.

Chapter 6

The Punchline — Why This Changes Everything

Let’s bring it all together. Here is the fundamental difference between a fixed SSM and Mamba.

Fixed SSM

  • Every token treated equally
  • Importance = recency
  • Cannot do content-based filtering
  • State dominated by “is” (31.2%)
  • Function words pollute memory

Mamba (Selective SSM)

  • Each token controls its own gate
  • Important tokens write strongly
  • Noise is suppressed automatically
  • State dominated by “France” (65.5%)
  • Learned, content-aware filtering

When the model sees “The capital of France is ___”, Mamba’s state is dominated by “France” at 65.5%. A fixed SSM’s state is dominated by “is” at 31.2%. Which one is more likely to correctly predict “Paris”?

Selectivity is not an optimization.
It is a necessity.

Without input-dependent parameters, a sequence model is fundamentally blind to content. Mamba’s selective mechanism gives SSMs the ability to choose what to remember and what to forget — the same ability that makes attention so powerful, but achieved through elegant gating rather than quadratic computation.
