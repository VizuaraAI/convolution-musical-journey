Core Intuition

Receptive field means “which earlier tokens can affect me?”

In one layer

If token 12 can only attend to tokens 9, 10, 11, and 12, then after one layer it directly knows about only the phrase:

the9 dusty10 mat11 yesterday12
Layer 1 at token 12 sees 9..12

After stacking

Token 12 in layer 2 reads layer-1 tokens near it. But those layer-1 tokens already contain their own local history. So the reachable input tokens expand leftward.

red6 key7 under8 the9 dusty10 mat11 yesterday12
Layer 2 at token 12 sees roughly 6..12
Plain-English version: a layer is not only reading raw words. It is reading summaries made by the previous layer. Those summaries already carry nearby context, so context travels like a relay.

Why It Matters

Local windows save attention work, but recall is limited by depth.

Full attention

Every token can directly attend to every previous token in a single layer. Great recall, expensive for long contexts.

Work per layer ≈ N × N

Sliding window attention

Every token attends to only a fixed local window. Much cheaper, but a far-away token needs multiple layers to influence the current token.

Work per layer ≈ N × W

Exact formula versus the classroom shortcut

If W means total causal tokens including the current token, the exact receptive field after L layers is:

RF = 1 + L × (W - 1)

With W=4 and L=3, that is 1 + 3×3 = 10 tokens. Many diagrams use the rough shortcut W×L, or define W as “new left positions per layer,” which gives the clean intuition: about 4×3 = 12 positions.

This is why some architectures mix local/sliding-window layers with occasional full-attention or global-token layers: local attention is cheap, while occasional global mixing restores long-range recall.
