Receptive field tracking

How a small sliding window sees farther after three transformer layers.

Sliding window attention sounds like the model is trapped inside a tiny local neighborhood. But stacked transformer layers create relay paths: token 12 can receive information from farther tokens through intermediate tokens in lower layers.

One sentence anchor

We will follow the final token “chapel”. At one layer it only reads nearby words. By layer three, older words like “violinist” can influence it indirectly.

window W = 4 · layers L = 3

Exact count depends on convention. Here W = 4 means “current token plus previous 3,” so the exact reachable span is 4 → 7 → 10. Many diagrams summarize the idea as about W × L.

1. The sentence

We track what can influence the last word.

Here are 12 tokens. The target is token 12, chapel. In a normal causal transformer, token 12 could directly attend to every earlier token. In sliding window attention, it can directly attend only to the local window.

2. One layer

A sliding window is a local reading rule.

At any layer, each token reads only a small group near itself. With W = 4, token 12 reads: token 9, token 10, token 11, and token 12.

This is not the circular buffer yet. This is the attention rule: “do not look farther back than the last W tokens.” The circular buffer is one efficient way an inference engine stores only those recent KV slots.

Layer 1 direct view for token 12

3. Layer stacking

Layer 3 does not read old tokens directly. It reads summaries that already contain old tokens.

4. The relay path

Far information moves through nearby tokens.

Token 12 at layer 3 does not directly draw an attention edge to token 3. Instead, it can read token 9 at layer 2. Token 9 at layer 2 can read token 6 at layer 1. Token 6 at layer 1 can read token 3 from the input.

That chain is receptive field growth. Each layer adds another local hop. The model gets farther context without each individual layer needing full attention.

One possible route from “violinist” to “chapel”

5. Attention rule vs implementation

The circular buffer is the KV-cache storage trick, not the whole mathematical idea.

Sliding window attention is the model rule: each token attends only to a recent window. During inference, a serving engine can exploit that rule by storing K and V vectors in a fixed-size circular buffer.

slot = token_position mod W

The slot number is storage only. The true token position is still needed for causal masks and positional encodings such as RoPE.

Example: W = 8 cache slots
